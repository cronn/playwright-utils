# Getting Started

`@cronn/playwright-utils` is a collection of utilities for writing tests with [Playwright](https://playwright.dev/), covering test setup, API testing and file snapshots.

## Installation

::: code-group

```sh [pnpm]
pnpm add -D @cronn/playwright-utils
```

```sh [npm]
npm install -D @cronn/playwright-utils
```

```sh [yarn]
yarn add -D @cronn/playwright-utils
```

:::

`@cronn/playwright-utils` requires `@playwright/test` and `@cronn/playwright-file-snapshots` as peer dependency.
